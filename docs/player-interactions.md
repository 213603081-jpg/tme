# 唱片机交互

先点击唱片机机身进入近景。未选歌时，点击播放键或唱针会播放默认歌单。

| 控件 | 操作 | 功能 | 反馈 |
| --- | --- | --- | --- |
| 上一首 | 点击 | 循环切换到当前歌单上一首 | 按键下压回弹、唱针抬起、唱片升起缩小再落下 |
| 播放 / 暂停 | 点击 | 播放或暂停当前歌曲 | 按键下压回弹，唱针转向唱片或归位，唱片渐进启停 |
| 下一首 | 点击 | 循环切换到当前歌单下一首 | 按键下压回弹、唱针抬起、唱片换片动画 |
| 唱针 | 点击 | 与播放 / 暂停键相同 | 唱针摆动，唱片渐进启停 |
| 唱针 | 向左 / 向右拨动超过 24 屏幕像素后松开 | 上一首 / 下一首 | 唱针抬起及换片动画；不会同时触发暂停 |
| 发光显示屏 | 自动更新 | 歌名、歌手、播放状态、时间、进度、转速、音量、音调 | 青蓝发光文字、扫描线、长歌名滚动和播放时的装饰电平动画 |
| 音量旋钮 | 向上 / 向右拖动增加；向下 / 向左减少 | 调整实际音量，范围 0–100% | 旋钮指针平滑转动，显示屏数值同步 |
| 音调旋钮 | 向上 / 向右拖动更明亮；反向更柔和 | 高频搁架滤波，范围 −12 至 +12 dB | 旋钮指针转动，显示屏数值同步 |
| 33 / 45 转速开关 | 点击 | 切换转速与播放速度，45 档约为 1.36 倍速，保留音高 | 开关滑动，唱片转速变化，显示屏同步 |
| 歌单中的播放 | 选择歌单后点击播放 | 换成该歌单并从第一首开始 | 唱片换片动画，中心封面更新 |

选片后自动关闭歌单并返回唱片机近景，预留 0.9 秒让镜头靠近。随后执行约 4.2 秒的换片：唱针抬起归位、旧唱片停转抬离主轴并向左移出、新唱片从右侧送入并落到主轴、唱片加速、唱针落下，音乐从头开始。旧唱片移出时保留旧封面，新唱片送入时才更新中心封面，唱片始终保持原尺寸。

换片期间暂时锁定播放和切歌，完成后恢复。曲目结束后自动循环到下一首。电平条为状态装饰动画，不代表实际音频频谱。系统开启减少动态效果时取消唱片移出与唱针升降动作。
